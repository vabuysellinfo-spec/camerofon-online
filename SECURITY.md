# Security

Do not open public issues containing passwords, signing keys, Firebase credentials, private configuration files, or device identifiers.

The following files are never part of this repository:

- `camerofon-release.keystore`
- `keystore.properties`
- `Camerofon-Signing-PRIVATE-FINAL.7z`

Only APK files signed with the official Camerofon release key should be attached to GitHub Releases.
